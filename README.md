# Презентації

Сайт-збірка шкільних презентацій: https://shavik16.github.io/site_mega/

| Презентація | Папка | Посилання |
|---|---|---|
| Вплив шкідливих звичок на людину (UA) | `harmful-habits/` | https://shavik16.github.io/site_mega/harmful-habits/ |
| TikTok and Its Influence on Modern People (EN, 11-І) | `tiktok/` | https://shavik16.github.io/site_mega/tiktok/ |

Керування: ← → (або клік / свайп), **F** — повний екран.
У «Шкідливих звичках» **N** показує текст виступу, а `#3` в кінці посилання відкриває одразу 3-й слайд.
TikTok відкривається за завісою — **Enter**, пробіл або тап (клік) по завісі.

Як додати нову презентацію: поклади її `index.html` в окрему папку, прев'ю 960×540 — у `thumbs/`,
і скопіюй одну картку в головному `index.html`.

Старе портфоліо — у гілці `portfolio-archive`.
